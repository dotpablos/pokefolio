# Pokefolio, a pokémon themed developer portfolio
This is a personal project of mine that I initially used to challenge myself to make my third (and hopefully last) developer portfolio that I can continue to iterate on forever.
Pokéfolio is an interactive game experience where users can enter different houses in a 2D sprite map in order to learn about my projects.
You can visit the hosted version of this repo at the following URL: https://www.lukepe.com

## Tech stack
- Node
- Phaserjs
- React
- Tailwind
- Nextjs

### Notes
There is a lot of weird stuff I had to do to make this project work the way I envisioned and to get my sprite map to work correctly with Nextjs. If you have any questions, please reach me on Github or submit an issue!
